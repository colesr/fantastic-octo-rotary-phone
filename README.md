# The Memphis Rite

A dependency-free, interactive digital exhibit for library-linked public reading, exploring how nineteenth-century Masonic periodicals described the Rite of Memphis.

Open `index.html` in a modern browser. No build step or server is required.

The exhibit uses original interpretive writing based on supplied historical-periodical material. That material contains competing origin stories, inconsistent degree counts, and strongly critical institutional opinions. This site presents those as archival claims and viewpoints, not as settled history or a guide to Masonic practice.

The current presentation is tuned for access from the Samuel Crocker Lawrence Library website, with stronger visitor orientation, calmer default motion, a visible sources-and-method framing section, and clearer navigation for first-time readers.

Use **Exhibit controls** in the header to choose among five color fields, adjust type scale and paper grain, activate reading focus or ambient motion, and enable **Super Animation Mode**. Motion effects honor the operating system's reduced-motion preference.

The added 1881 context is linked in the exhibit to a modern public reference on Memphis–Misraim; it is presented as a later reference account, not as a resolution of the periodical record.

The **Architectures** section adds an animated, interactive comparison of the supplied material's 33- and 99-degree published models, plus later twentieth-century history. It intentionally summarizes organization and chronology rather than reproducing the source's degree tables or ceremonial descriptions. The pasted public-reference page included its own reliability warning, so all of these claims remain explicitly contextualized within the exhibit.

The exhibit also includes a visible orientation section, a contents list, a text-path companion to the degree constellation, a return link to the library page, and an explicit **Sources, method, and use** section near the end.
